# Dirección visual de [producto]

## Usuario y tarea

Usuario principal, tarea que debe completar y funciones existentes que se preservan. Alcance de esta iteración y evidencia que la dará por terminada.

## Dirección y referencias

Personalidad visual vinculada al producto. Una o dos referencias con URL/origen: principios aprendidos y decisiones originales. No copiar marcas, pantallas ni assets propietarios.

## Sistema visual

| Área | Decisión | Verificación |
|---|---|---|
| Tipografía | Familias, licencia, fallbacks, tamaños, pesos e interlineado | Texto real y zoom 200 % |
| Color | Fondo, superficie, texto, borde, acción, foco, éxito, aviso, error | Contraste medido por pares/estados |
| Composición | Grid, ancho útil, escala de espacios y densidad | Escritorio, móvil y contenido largo |
| Componentes | Reutilizados/nuevos, bordes, radios, elevación | Consistencia entre páginas/estados |
| Responsive | Orden, columnas, navegación, tablas y controles | Viewports concretos; sin scroll global accidental |
| Movimiento | Propósito, duración y reduced-motion | Sin bloquear tareas ni mover controles de sitio |

## Estados e interacción

Vacío, carga, error, éxito, deshabilitado, hover, focus y teclado. Fuente de datos y acción real de cada control. Comportamiento ante respuestas antiguas o red caída.

## Evidencia

Comando/URL real, viewports, capturas inspeccionadas, flujo probado, consola/red, contraste, checks ejecutados y defectos antes/después. Pendientes o límites sin afirmaciones de pruebas no realizadas.
